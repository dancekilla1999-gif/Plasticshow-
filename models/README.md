# Модели для 3D‑печати

## Ажурная овальная рама, 380 мм, две части

Рама доработана под печать: сплошная панель («зеркало»), закрывавшая овал
в исходной модели, удалена — середина полностью открыта. Поверхность сглажена
одним проходом Loop‑сабдивижна, потому что на таком размере исходная
триангуляция читалась гранями. Модель разрезана поперёк на две части, которые
после склейки дают ровно **380.000 мм** в длину.

| Файл | Габариты, мм | Объём | Треугольников |
|---|---|---|---|
| `frame-380mm-part-A-bottom.stl` | 208.8 × 201.0 × 30.1 | 225.1 см³ | 290 968 |
| `frame-380mm-part-B-top.stl` | 205.0 × 184.0 × 29.8 | 200.3 см³ | 254 712 |

Обе части замкнутые, по одной оболочке, без дыр и non‑manifold рёбер. Каждая
центрирована по XY и лежит на плоскости Z = 0 лицевой стороной вверх.

### Стол принтера

Нужно поле не меньше **209 × 201 мм**. Помещается на 220 × 220 и крупнее.
Габарит по Y у части B (184 мм) включает 5 мм выступающих штифтов — на общую
длину склеенной рамы они не влияют, штифты уходят в гнёзда части A.

### Соединение

Два шипа ромбового сечения на части B и ответные гнёзда в части A:

| | |
|---|---|
| Шип | ромб с полудиагональю 6.0 мм, вылет 5 мм |
| Гнездо | ромб с полудиагональю 6.25 мм, глубина 5.8 мм |
| Зазор | 0.25 мм по диагонали |
| Стенка вокруг шипа | 3.1 мм |
| Материал за шипом | 10.2 и 10.9 мм |

Сечение выбрано ромбом не для красоты: все его грани стоят под 45° к столу,
поэтому и шип, и гнездо печатаются без поддержек и без мостов — круглый штифт,
лежащий на боку, так не умеет.

Шипы задают положение однозначно, поэтому склейка сводится к «вставить и
прижать». Клей — цианакрилат или эпоксидка по площади среза (~460 мм² на
каждой из двух точек контакта).

### Печать

Рама вылеплена объёмно с обеих сторон, плоской спинки нет — при печати плашмя
нужны поддержки под нависающим декором.

Другой размер получается пропорциональным масштабированием обеих частей на
одинаковый процент; линия склейки при этом остаётся стыкуемой.

Файлы собраны скриптом
[`scripts/build-frame-parts.py`](../scripts/build-frame-parts.py) — он же
проверяет геометрию и печатает контрольные цифры.
