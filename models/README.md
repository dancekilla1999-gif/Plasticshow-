# Модели для 3D‑печати

## `frame-openwork-200mm.stl`

Ажурная овальная рама, доработанная под печать: сплошная панель («зеркало»),
которая закрывала овал в исходной модели, удалена — середина полностью открыта.
Сам декор рамы не изменён.

| | |
|---|---|
| Габариты | 109.8 × 200.0 × 16.4 мм |
| Объём материала | 62.0 см³ |
| Треугольников | 138 582 |
| Геометрия | замкнутая, одна связная оболочка, без дыр и non‑manifold рёбер |
| Положение | центрирована по XY, лежит на плоскости Z = 0 лицом вверх |

Исходная модель безразмерная (1.09 × 1.99 × 0.163), поэтому размер выбран так,
чтобы высота была 200 мм — коэффициент 100.6178. Другой размер получается
пропорциональным масштабированием в слайсере: 150 мм → 75 %, 300 мм → 150 %.

Рама вылеплена объёмно с обеих сторон, плоской спинки нет, поэтому при печати
плашмя нужны поддержки под нависающим декором.

Файл собран скриптом [`scripts/open-frame-center.py`](../scripts/open-frame-center.py).
