# Cobra X — накладки на чашки AirPods Max

Параметрическая модель «оплавленной паутины» на внешние чашки AirPods Max:
две зеркальные детали (левая и правая) плюс примерочное кольцо для проверки
посадки перед печатью полного комплекта.

![правая чашка](stl/cobra-x_right.png)

Геометрия строится не вручную, а генератором `cobra_x.py`: сеть жил
раскладывается по развёртке поверхности чашки, собирается в поле расстояний
(SDF) и вынимается марширующими кубами. На выходе — замкнутая манифолдная
сетка, слайсер берёт её без ремонта.

---

## Файлы

| Файл | Что это |
|---|---|
| `stl/cobra-x_right.stl` / `.3mf` | правая чашка |
| `stl/cobra-x_left.stl` / `.3mf` | левая чашка |
| `stl/cobra-x_fit-gauge.stl` / `.3mf` | примерочное кольцо (печатать первым) |
| `cobra_x.py` | генератор: любые размеры и рисунок |

`.3mf` и `.stl` — одна и та же геометрия; `.3mf` в пять раз легче и его
понимают PrusaSlicer, OrcaSlicer, Bambu Studio, Cura, Chitubox.

Параметры детали: габарит ≈ 90 × 104 × 20 мм, объём ≈ 10 см³
(≈ 12 г PLA или ≈ 11 г смолы на чашку), стенка жилы 3.5 мм по контакту,
2.6 мм над поверхностью.

## Сначала — примерка

Размеры чашки взяты по общедоступным габаритам AirPods Max, а не по 3D-скану
конкретного экземпляра. Разброс между партиями и разная толщина краски дают
±0.3–0.5 мм, поэтому **сначала печатается `cobra-x_fit-gauge`** — тонкое
кольцо высотой 8 мм с той же внутренней поверхностью, что и у накладки.
Печать 10–15 минут, пластика на 2 грамма.

* кольцо садится с лёгким щелчком и не болтается → печатайте накладки как есть;
* садится туго / не доходит до конца → увеличьте зазор:
  `--clearance 0.5`;
* болтается → уменьшите: `--clearance 0.2`, при необходимости
  подгоните и сам контур `--cup-w` / `--cup-h`.

Как измерить свою чашку: штангенциркулем по внешнему алюминиевому колпаку —
ширина поперёк головы (`--cup-w`, по умолчанию 84 мм) и высота вдоль
(`--cup-h`, 98 мм).

## Печать

**FDM.** Ориентация: пояском (нижней кромкой) на стол, куполом вверх.
Поясок даёт сплошную опорную площадку — прилипание отличное.

| Параметр | Значение |
|---|---|
| Слой | 0.16–0.2 мм |
| Сопло | 0.4 мм |
| Периметры | 3–4 (жила пропечатывается насквозь, заполнение не важно) |
| Заполнение | 15 % |
| Поддержки | древовидные, **только с чашей внутрь**, зазор 0.2 мм |
| Материал | TPU 95A (садится и снимается многократно) или PLA / PETG |

Купол внутри — нависание, без поддержек центральная часть провиснет.
Древовидные поддержки внутри чаши отламываются целиком.

**Смола (SLA/DLP).** Наклон 30–40°, поддержки на внутреннюю сторону, кончик
0.35 мм. Детализация выше, поверхность под хром готовится минимальной
шкуркой. Берите прочную смолу (ABS-like / tough), обычная стандартная
хрупкая — тонкие жилы лопнут при надевании.

**Хром как на фото** — это не пластик, а покрытие: грунт-филлер →
шлифовка 800/1500 → «хромовая» краска (Molotow Liquid Chrome, Montana
Chrome) или гальваника/вакуумная металлизация в мастерской. Печать в
серебристом PLA сама по себе такого зеркала не даст.

## Посадка и защёлка

Накладка держится тремя вещами:

1. юбка заходит на 7 мм на борт чашки;
2. сплошной поясок по нижней кромке пружинит и обхватывает борт;
3. внутренний буртик 0.45 мм заходит под перегиб борта — это и есть щелчок.

Для жёсткого PLA буртик можно убрать (`--lip 0`), иначе накладка ставится
туго и есть риск сколоть жилу. Для TPU оставляйте как есть.

Сверху оставлено окно шириной 44 мм — под дужку, колесо Digital Crown и
кнопку шумоподавления. Ширину меняет `--window`.

## Генератор

```bash
pip install numpy scipy scikit-image
python3 cobra_x.py --side both --preview        # обе чашки + PNG-превью
python3 cobra_x.py --side gauge                 # примерочное кольцо
```

Основные параметры:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `--cup-w`, `--cup-h` | 84, 98 | габарит чашки, мм |
| `--cup-n` | 2.35 | «прямоугольность» контура |
| `--dome` | 9.0 | выпуклость внешней поверхности, мм |
| `--clearance` | 0.35 | зазор до чашки, мм |
| `--skirt` | 7.0 | заход юбки на борт, мм |
| `--rim` | 2.6 | высота сплошного пояска, мм |
| `--lip` | 0.45 | буртик-защёлка, мм |
| `--window` | 22.0 | полуширина верхнего окна, мм |
| `--cell` | 12.5 | размер ячейки сети, мм |
| `--strut` | 1.9 | радиус жилы, мм |
| `--prune` | 0.34 | доля выброшенных рёбер (крупнее ячейки) |
| `--drips` | 14 | висящие «капли» |
| `--seed` | 7 | зерно рисунка — меняет узор целиком |
| `--voxel` | 0.45 | шаг сетки: меньше — точнее и тяжелее файл |

Свой узор — просто другое зерно:

```bash
python3 cobra_x.py --side both --seed 42 --cell 15 --strut 2.2 --preview
```

Толще и «мясистее», как на референсе:

```bash
python3 cobra_x.py --side both --strut 2.4 --strut-var 0.7 --prune 0.42 --blend 1.2
```

Генерация обеих чашек — около 12 секунд.
