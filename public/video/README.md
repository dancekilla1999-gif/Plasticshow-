# Видеофайлы

Сюда кладутся видео проекта. После этого добавьте запись в
`src/content/videos.ts` — страница `/video` сама переключится с состояния
«готовится» на сетку с плеером, а в hero на главной появится кнопка шоурила.

## Требования

| Параметр | Значение |
|---|---|
| Формат | MP4 (H.264 + AAC) — понимают все браузеры |
| Разрешение | 1920×1080 достаточно; 4K избыточен для веба |
| Битрейт | 4–6 Мбит/с для шоурила, 2–4 для отдельных номеров |
| Длительность шоурила | 60–90 секунд |
| Размер файла | до ~30 МБ на ролик |
| Звук | обязателен для шоурила; для фоновых — дорожку можно вырезать |

## Как сжать

```bash
ffmpeg -i исходник.mov -vf "scale=1920:-2" -c:v libx264 -crf 24 \
  -preset slow -c:a aac -b:a 128k -movflags +faststart shoreel.mp4
```

`-movflags +faststart` обязателен: без него браузер ждёт загрузки всего файла
перед началом воспроизведения.

## Пример записи в src/content/videos.ts

```ts
export const VIDEOS: Video[] = [
  {
    id: 'showreel',
    title: 'Шоурил 2026',
    kicker: 'Showreel',
    src: '/video/showreel.mp4',
    poster: 'carnival-hero',   // любой slug из media.generated.ts
    duration: '1:24',
    description: 'Общий шоурил проекта',
  },
];
```
