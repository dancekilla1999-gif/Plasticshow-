# Сгенерированные изображения

Файлы в этой папке создаются автоматически командой `npm run media`
из фотографий в `assets/photos/`. Вручную сюда ничего класть не нужно.

## Как добавить фотографию

1. Положить `.jpg` / `.jpeg` / `.png` в `assets/photos/` с понятным именем
   (имя файла становится slug'ом: `swan-lake.jpeg` → `swan-lake`).
2. Выполнить `npm run media`.
3. Сослаться на slug в `src/content/` — например в `cover` постановки.

Скрипт создаст AVIF и WebP шириной 480 / 768 / 1200 / 1800 px и запишет
размеры с blur-заглушкой в `src/content/media.generated.ts`.

## Требования к исходникам

- Минимальная ширина 1600 px по длинной стороне, лучше 2000+.
- Без вотермарок и логотипов площадок поверх кадра.
- Вертикальные кадры (3:4, 4:5, 9:16) — для плиток и портретов.
- Горизонтальные (16:9, 3:2) — для широких блоков и обложек видео.
